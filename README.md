Сценарий создания встречи и записи

Создание типа встречи. Владелец открывает раздел типов встреч, нажимает «Создать», указывает название, описание, продолжительность и доступное время, затем сохраняет настройки.
Выбор времени. Пользователь открывает страницу записи, выбирает тип встречи, просматривает календарь и выбирает свободную дату и время.
Оформление записи. Пользователь вводит необходимые контактные данные и подтверждает бронирование.
Просмотр записи. Владелец открывает список записей и видит новое бронирование с именем участника, типом встречи, датой и временем.
Результат: подтверждённая запись появляется в списке встреч владельца.

В рамках сценария: регистрация пользователей, подключение внешних календарей и настройка уведомлений не рассматриваются.
