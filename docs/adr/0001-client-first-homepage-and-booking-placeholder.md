# Главная страница ориентирована на клиентов и ведёт на заглушку записи

Первая версия главной страницы Meetly обращается прежде всего к клиентам: её основной призыв «Выбрать встречу» ведёт на `/booking`. Поскольку каталог и полноценная запись ещё не реализованы, этот маршрут остаётся честной заглушкой; отдельный CTA для специалистов, обещание подтверждения бронирования и неподтверждённые маркетинговые утверждения исключены. Это сохраняет простой клиентский путь, не создавая ожиданий недоступных функций.
