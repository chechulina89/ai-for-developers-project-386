# Клиентский сценарий записи использует временный API

Главная страница Meetly ориентирована на клиентов: призыв «Выбрать встречу» ведёт на `/booking`, где предложение и доступность загружаются через сгенерированный API SDK. Гость может выбрать дату и время и создать подтверждённое бронирование; владелец входит на `/owner` и просматривает будущие встречи.

На текущем этапе профиль специалиста демонстрационный, а бронирования, идемпотентность и сессии хранятся в памяти одного процесса. Данные могут исчезнуть после перезапуска, поэтому интерфейс явно предупреждает не вводить реальные персональные данные. До production необходимы реальный профиль и отдельно согласованное постоянное хранилище.
